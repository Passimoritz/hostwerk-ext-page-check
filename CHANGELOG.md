## 1.1.0

- New area “Security”: HTTPS (local test addresses excepted), HSTS, Content Security Policy, X-Content-Type-Options, Referrer-Policy and protection against framing. / Neuer Bereich „Sicherheit“: HTTPS (außer lokalen Testadressen), HSTS, Content Security Policy, X-Content-Type-Options, Referrer-Policy und Schutz vor Einbetten.
- robots.txt (also whether it locks out every search engine) and sitemap.xml are checked; new check for the heading order h1–h6. / robots.txt (auch, ob sie alle Suchmaschinen aussperrt) und sitemap.xml werden geprüft; neue Prüfung der Überschriften-Reihenfolge h1–h6.
- “Whole website”: follows the links of the site up to N pages and checks every link once. / „Ganze Website“: folgt den Links der Website bis zu N Seiten und prüft jeden Link einmal.
- Regular checks (daily/weekly) with a message and a watcher entry when the score drops by 5 points or more. / Regelmäßige Prüfungen (täglich/wöchentlich) mit Meldung und Wächter-Eintrag, wenn die Punktzahl um 5 oder mehr fällt.
- Minimum score before publishing: the service `pageCheck` (check, gate) for other extensions such as “Publish pages”. / Mindestpunktzahl vor dem Veröffentlichen: Dienst `pageCheck` (check, gate) für andere Erweiterungen wie „Seiten veröffentlichen“.
- Tab on every project and in the web server area; error state with “Try again”; the page sits under “Develop” after the projects; a shortcut to assign; other extensions may add tabs. / Reiter auf jedem Projekt und im Webserver-Bereich; Fehlerzustand mit „Erneut versuchen“; die Seite steht unter „Entwickeln“ hinter den Projekten; ein Tastenkürzel zum Belegen; andere Erweiterungen dürfen Reiter ergänzen.
- Sizes from the design scale. The release packs everything except the repository tooling. / Größen aus der Design-Skala. Das Release packt alles außer dem Repo-Werkzeug.
